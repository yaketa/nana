# nana

Claude に開発をまかせて、あなたは「何を作るか」と「使った感想」に集中するための
リポジトリです。

## いま作っているもの

長野県の“ゼロ磁場”パワースポット **分杭峠（ぶんぐいとうげ）** の紹介サイトです。

- 見る: ブラウザで `index.html` を開く（公開後は https://yaketa.github.io/nana/ ）
- しくみ: フレームワークなしの HTML + CSS が 1 ファイルに入っているだけ
- 公開: main が更新されると、自動で GitHub Pages に反映されます

### サイトをインターネットに公開するには（最初の 1 回だけ）

GitHub の設定を 2 か所さわる必要があります（無料プランの GitHub Pages は
「公開リポジトリ」でしか使えないため）。

1. GitHub でこのリポジトリを開き **Settings** へ
2. ページ一番下の **Danger Zone** → **Change repository visibility** →
   **Make public**（リポジトリ名の入力を求められます: `yaketa/nana`）
3. 同じ Settings の左メニュー **Pages** → Build and deployment の
   **Source** を **GitHub Actions** に変更
4. Claude に「公開設定したよ」と伝えると、公開の実行と確認まで行います

## 開発の回し方

1. 作りたいもの・直してほしいことを、ふだんの言葉で Claude に伝える
2. Claude が作り、動くことを確認して、PR（変更の提案）を出す
3. Claude が渡すリンクを開き、緑のチェックを確かめて「Merge」ボタンを押す
4. できたものを触ってみて、気になることがあればそのまま伝える → 1 に戻る

「なんか変」「ちょっと重い気がする」くらいの言い方で十分です。
原因を調べるのは Claude の仕事です。

## 役割分担

- あなた: 何を作るか決める / 触って感想を言う / 好みを聞かれたら選ぶ / Merge ボタンを押す
- Claude: 実装 / 原因調査 / 動作確認 / Git や PR の操作 / わかりやすい説明

あなたが決めたことは CLAUDE.md というファイルに記録されていきます。
見ても見なくても大丈夫です。

## 魔法の言葉

- 「戻して」 — 直前の変更を取り消してくれる（取り消しも PR で来ます）
- 「今どうなってる？」 — いまの状態をやさしく説明してくれる
- 「もっと簡単に説明して」 — 説明をかみ砕き直してくれる
- 「本当にそれでいい？」 — Claude が自分の答えを見直してくれる
- 「/tap」 — スマホで打つのがつらいとき。質問や次の一手をタップで選べるモードになる

## 困ったとき

- 何かが壊れた気がしたら、そのまま伝えてください。調査も復旧も Claude がやります
- 会話が長くなって迷子になったら、新しいセッションを始めて大丈夫です。
  必要な決まりごとはこのリポジトリの中に書いてあるので、ちゃんと引き継がれます
